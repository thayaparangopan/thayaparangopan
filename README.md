### 01 · 🧠 Intelearn — Emotion-Adaptive Learning Platform

**Personalizing digital learning through emotion-aware technology.**

Intelearn is an AI-powered learning platform designed to adapt learning experiences to students' emotional states. It combines emotion recognition with interactive learning activities to create a more engaging and supportive digital learning environment.

**Key Features**
- 🧠 Emotion-aware learning experiences
- 🎮 Interactive mini-games, riddles, and revision activities
- 🤖 AI learning mentors — Dhruv and Maya
- 📱 Mobile-first learning experience

**Technology Stack**

`React Native` `JavaScript` `Node.js` `Express.js` `TensorFlow Lite`

🔗 **[Explore Intelearn on GitHub](https://github.com/thayaparangopan)**

### 02 · 🎨 UIForge AI — AI-Powered UI-to-Code Generation

**Bridging the gap between visual design and frontend development.**

UIForge AI is an AI-based project focused on transforming UI screenshots into frontend code. It aims to streamline the design-to-development workflow through visual analysis, code generation, interface comparison, and AI-assisted refinement.

**Key Features**
- 🖼️ Screenshot-based interface input
- 🔍 Analysis of layouts, components, colors, and spacing
- 💻 AI-assisted frontend code generation
- 👀 Comparison of reference designs and generated interfaces
- ✨ Natural-language UI refinement

**Technology Stack**

`React` `TypeScript` `Tailwind CSS` `Python` `FastAPI` `Gemini API` `PostgreSQL`

🔗 **[Explore UIForge AI on GitHub](https://github.com/thayaparangopan/UIForge-AI)**

### 04 · 🚚 CecilGo — Smart Vehicle Tracking System

**Key Features**

- 🗺️ Map-based vehicle visualization
- 🚛 Vehicle movement and trip monitoring
